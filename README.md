# literature-workbench-with-codex
一款面向科研人员的 Windows 本地文献阅读与分析工具，支持 PDF 阅读、全文检索、阅读位置恢复、选段批注、书签、Markdown 笔记和会话管理。 工作台能够识别普通数字 PDF、混合 PDF 以及扫描类 PDF。对于缺少文字层的扫描文档，系统可调用 Tesseract OCR 提取正文，并保留页码、文字块、解析来源和版本信息，便于检索和引用核验。 用户还可以在本地选择页面、选段或检索结果作为上下文，通过 Codex CLI 进行文献总结、概念解释、方法梳理、假设检查和论证分析。文献库、解析结果、笔记和会话默认保存在本机，适合个人科研阅读和文献整理。
